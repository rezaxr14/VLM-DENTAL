\begin{abstract}
Vision-language models (VLMs) fail structurally on panoramic dental radiographs: the best frontier
models reach only 36--46\% exact-match accuracy against expert labels on the DENTEX benchmark
while reporting 0.85--0.95 confidence on hallucinated tooth positions (ECE up to 0.68), and a
dense 11B generalist falls below the statistical majority class --- because one forward pass
cannot zoom into sub-patch pathology, resolve the modality's left/right display convention, or
verify an anatomical hypothesis before committing to it. We present \textbf{VLM-DENTAL}, an
agentic VLM built on a different contract between the policy and its tools: \emph{grounding is a
hypothesis to interrogate, not an answer to trust}. (1) The policy can correct its learned
grounding tool via \texttt{nudge\_crop}, a data-only tool taking box-relative fractional shifts
and rescales that a VLM can reason about linguistically. (2) A \emph{tiered perturbation}
mechanism makes this skill learnable from synthetic demonstrations: the demonstrator experiences
deliberately imperfect tool output (45\% clean / 25\% small / 30\% large offsets, decoupled from
the detector's real error rate so demonstrations never go stale, and never announced verbally so
the offset magnitude alone carries the signal). (3) The eight-tool interface exposes continuous
effect parameters (denoise strength, window center/width, contrast factor, crop context), so tool
calls carry \emph{how much}, not just \emph{which}. (4) GRPO reinforcement learning uses a
ground-truth-anchored composite reward with multi-finding set matching, whose efficiency term
exempts locate-and-correct calls so the reward never prices out the behavior it teaches. A
corpus-level analysis of 3{,}694 verified, decontaminated synthetic traces shows a clean judgment
gradient --- corrective nudges on 38.4\% of large tool errors, 13.6\% of ambiguous ones, 1.1\% of
clean outputs (ground-truth-anchored pathology locates), with recoveries up to IoU
$0.07 \to 0.94$ --- genuine visually-driven self-correction rather than scripted steps. Evaluation
follows DENTEX-native, leaderboard-comparable set-matched metrics with paired bootstrap intervals
and a frozen, leak-free protocol; end-to-end training results are reported as runs complete. We
position the work relative to concurrent dental agentic systems and release the corpus, audit
tooling, and all figure/table sources for regenerability.
\end{abstract}
