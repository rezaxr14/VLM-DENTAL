\section{Introduction}
\label{sec:intro}

A panoramic radiograph (OPG) is a single wide X-ray that shows all teeth and both jaws. A dentist reads it tooth by
tooth: each tooth is named in FDI notation (a quadrant digit from 1 to 4 followed by a position from 1 to 8, so
``34'' is the fourth tooth from the midline in the lower left), and each abnormal tooth is given a diagnosis. The
DENTEX benchmark \citep{hamamci2024dentex} uses four: caries, deep caries, periapical lesion, and impacted tooth.

Panoramic dental radiograph analysis requires assigning diagnostic findings to individual
teeth in standard FDI notation. General-purpose vision-language models (VLMs) offer a flexible
interface, but in our zero-shot evaluation on DENTEX they agree only weakly with expert
annotations (\cref{sec:baselines}); the best pooled exact F1 is 0.222. Image-level hit rates
and calibration give complementary evidence but do not identify the causes of these errors.
Local detail, tooth identity, and orientation all matter, which motivates an agent that can
inspect a region again before answering.

Tool-using systems in medical and general domains provide relevant precedents
\citep{wu2026vtool,li2024mmedagent,zhang2025octotools,oralgptplus2026,oralagent2026}.
We focus on one failure point: a learned grounding model can return a plausible box for the
wrong region, and every subsequent crop inherits that error. Instead of treating the box as an
authoritative observation, the agent should be able to inspect and revise it. Whether a
trained agent acquires this behavior, and whether it improves diagnosis, are empirical
questions that the frozen evaluation design is built to answer.

This paper develops \sys{}, an agentic VLM for OPG diagnosis built on a different contract
between the agent and its tools: \emph{grounding is a hypothesis, not an answer}
(\cref{fig:mechanism}). \cref{fig:overview} shows the system, \cref{fig:internals} opens its model,
and \cref{fig:evidence} contrasts the two trace arms on one image. Our contributions are:

\begin{enumerate}[leftmargin=*,itemsep=2pt,topsep=3pt]
\item \textbf{A self-correcting grounding tool (\texttt{nudge\_crop}, \cref{sec:nudge}).}
The agent can shift and rescale a box it was \emph{already given}, whether by the grounding
model or by a previous correction, using box-relative fractional arguments (\texttt{dx\_frac},
\texttt{dy\_frac}, \texttt{scale}) that a VLM can reason about in words (``shift right about
half a tooth-width''), without re-running detection. Box revision thus becomes an explicit,
inspectable action rather than an implicit change in the model's internal localization.
\item \textbf{A tiered perturbation mechanism that makes self-correction learnable
(\cref{sec:perturbation}).} Demonstrating correction behavior requires a demonstrator that
\emph{experiences} tool error. During trace generation we return the expert-verified box for
annotated teeth, which keeps the task solvable, but perturb the box \emph{shown to the
demonstrator}, at fixed rates and without announcing the error. A corpus-level analysis
(\cref{sec:mechanism}) shows that corrective use of \texttt{nudge\_crop} rises with the size of the
offset. Whether the trained agent shows the same behavior remains to be measured.
\item \textbf{A tool interface with continuous parameters (\cref{sec:tools}).} Tools expose
\emph{how much} effect to apply (denoise strength, window center and width, a contrast factor, a
crop margin), so a tool call carries more than a tool name.
\item \textbf{A ground-truth-anchored, correction-friendly reward (\cref{sec:reward}).} GRPO
training \citep{deepseek2025r1} uses a composite reward whose dominant term is a hard,
non-LLM-judge match against expert labels with multi-finding greedy one-to-one matching
(F1-style harmonic mean of recall and precision). Its efficiency term scales a reference
budget with case complexity and \emph{exempts} \texttt{locate\_tooth} and \texttt{nudge\_crop}
from per-call cost, so the reward does not penalize the verification behavior it is meant to
teach.
\item \textbf{Label-anchored synthetic demonstrations and an audit trail
(\cref{sec:traces}).} 3{,}694 verified chain-of-thought tool-use traces over DENTEX and Tufts, in
exactly paired with-tools and no-tools arms, generated under real tool execution in a
LangGraph \citep{langgraph} loop, verified cross-family, decontaminated of directive leakage, and released with
their audit trail.
\end{enumerate}

We evaluate on DENTEX with its native structured metrics (pooled, set-matched, finding-level
precision, recall, and F1 with paired bootstrap intervals) against zero-shot frontier VLMs, the
same backbone with and without tools, and a supervised specialist detector. The corpus-level
analyses reported here are complete; the two-stage training results are pending and are marked as such
in the tables. Inference-time rules, skills, and serving optimizations are evaluated separately on the
training-derived dev split (\cref{sec:harness-serving}).
