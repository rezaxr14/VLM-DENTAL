# VLM-DENTAL Paper

LaTeX sources for the paper draft. Everything numeric is **generated** from the released trace
corpus by `scripts/paper/generate_paper_assets.py` — tables in `generated/`, figures in
`figures/` (every figure has an SVG source; PDFs are produced for pdflatex inclusion).

## Layout

| Path | Contents |
|---|---|
| `main.tex` | Preamble, title, abstract, section includes |
| `sections/01_intro.tex` … `06_conclusion.tex` | Body sections |
| `sections/07_appendix.tex` | Perturbation config, mechanism splits, grounding validation, verifier taxonomy, reproducibility |
| `refs.bib` | Bibliography — entries marked `% TODO-verify` **must be checked** before submission |
| `generated/*.tex` | **Generated** table fragments (do not edit; regenerate) |
| `figures/svg/*.svg` | Figure sources (SVG). Data figures are written by the asset script; the sixteen composited diagrams (`fig_concept`, `fig_gallery`, `fig_tools`, `fig_design`, `fig_pipeline`, `fig_architecture`, `fig_architecture_training`, `fig_trace_generation`, `fig_trace_verification`, `fig_traces_evidence`, `fig_traces_comparison`, `fig_corpus_composition`, `fig_datasets`, `fig_grounding_cv`, `fig_input_geometry`, `fig_perturbation_mechanism`) are generated by `build_diagrams.py`, which also checks every label against its box width and prints any overflow. The superseded hand-authored `fig_pipeline.svg` is archived at `scratch/paper_fig_backups/fig_pipeline_handauthored.svg.bak` |
| `figures/pdf/*.pdf` | Compile-ready twins produced from the SVGs |
| `figures/assets/` | Base64-embedded radiograph crops extracted from DENTEX image 624 by `build_diagrams.py` (plus `_assets_b64.json` cache) |
| `assets_summary.json` | Every number emitted by the asset script (check prose against this) |

## Tooling (in `scripts/paper/`)

| Script | Purpose |
|---|---|
| `generate_paper_assets.py` | Corpus stats, tool usage, nudge-vs-tier mechanism analysis, data figures, SVG→PDF conversion |
| `build_diagrams.py` | Generates the eight composited diagrams (real radiograph assets embedded as base64 data URIs; canonical views rendered by `dental_agent.utils.canonical`; the real returned box trajectory from trace 624; corpus/dataset/grounding numbers from `assets_summary.json` and `docs/YOLO_CV_RESULTS.md`) and converts them to PDF; `--preview` also writes PNG renders to `scratch/preview` |
| `verify_paper.py` | Static draft checks: labels, inputs, escaping, number consistency vs `assets_summary.json` |
| `preview_figures.py` | PNG previews of every figure for visual verification (writes to `scratch/preview`) |
| `extract_trace_examples.py` | Pull real with-tools / no-tools trace excerpts (same image) for the comparison figure |

Requires the canonical trace files under `data/traces/` and the DENTEX/Tufts image folders for
the example figure (paths default to this repo's layout). SVG→PDF conversion of the hand-authored
diagram uses `svglib` (pip install svglib reportlab); matplotlib figures are emitted as both SVG
and PDF directly.

## Compile

No LaTeX toolchain is required to edit; to build locally install TeX Live or MiKTeX, or use
Overleaf (recommended — this compiles with plain pdfLaTeX, no custom style files):

```bash
cd paper
pdflatex main && bibtex main && pdflatex main && pdflatex main
```

Packages used are standard: `graphicx, booktabs, natbib, hyperref, cleveref, xcolor, enumitem,
caption, microtype, placeins`.

## Rules for editing

1. **Never hand-edit `generated/*.tex` or `figures/svg/fig_*` data figures** — rerun the asset
   script instead. The sixteen composited diagrams are generated by `build_diagrams.py` (edit that
   script, then rerun it; it also refreshes the PDFs via `convert_diagrams`). Keep diagram
   canvases narrow (about 640-780 units) so labels print at 5-7 pt at `\linewidth`. After
   editing a diagram run `python scripts/paper/audit_diagram_text.py` (exit 1 if any label overflows its box).
2. **Pending results** are marked with `\todo{...}` (red). Fill them from
   `scripts/aggregate_eval.py` outputs over `data/evaluations/*` only — never from `docs/*`
   dashboards, which may be stale.
3. **Citations**: verify every `% TODO-verify` entry in `refs.bib` against the real sources.
4. **Novelty wording**: keep the "among the first … specifically the first with DENTEX-native
   evaluation, a clean tool/RL ablation, and a self-correcting grounding loop" framing; do not
   regress to an unqualified "first" (see `docs/dentex-agentic-vlm-proposal.md` §3.5 for the
   reasoning and the two concurrent systems that must be cited).
