# Thesis-style figures (archived)

Frozen copies of the original, dense "thesis-style" figure generators, kept for
the thesis. The paper itself moves to the Q1-style figures in
`scripts/paper/q1_figures/`.

- Scripts: `build_diagrams.py`, `build_mechanism_diagrams.py`,
  `diagram_common.py` plus the audit/preview helpers.
- Their SVG outputs are archived in `paper/figures/archive/svg/`.
- The active copies of these scripts still live in `scripts/paper/` and keep
  producing the figures that the current `main.tex` includes. To regenerate the
  thesis figures later, run the active copies, or copy these files back to
  `scripts/paper/` (they locate the repository root relative to that folder).
